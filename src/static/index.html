⚡ 模式一：Native iSCSI / iBFT SANBOOT (微軟官方免驅 · 推薦)
基於 Linux 原生 SCSI 目標（tgtadm），將虛擬磁碟映射為物理網絡塊設備並寫入 iBFT 表。Windows 原生 msiscsi.sys 免驅識別為本地硬盤啟動，速度最快，完全不修改虛擬磁碟內部檔案。

🌐 模式二：HTTP Range Direct SANBOOT (HTTP 206 協議直連)
透過 HTTP 206 協議分塊直讀虛擬磁碟，客戶端 iPXE 直接發起 HTTP SANBOOT 引導。完全免除外部 iSCSI 守護進程依賴，適合輕量網絡、WinPE 及無 iSCSI 內核支援環境。
HTTP 206 直連 免 iSCSI 守護進程 輕量引導 WinPE 友好
